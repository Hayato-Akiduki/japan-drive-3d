日本一周ドライブ 3D
====================

■ 起動
  JapanDrive3D.exe をダブルクリックしてください（.NET などのインストールは不要です）。
  初回に「WindowsによってPCが保護されました」と出たら、
  「詳細情報」→「実行」を押してください（署名のない自作アプリのため表示されます）。

■ モード
  1 日本一周モード … ★の10都市を巡って東京へ戻る（高速道路を走る）
  2 フリーモード   … 道路に関係なく日本中どこでも自由に走れる。速度制限なし
                     ↑を押し続けるほどどんどん速くなります。名所に近づくとスタンプ。
                     M の地図で左クリック＝その場所へワープ、右クリック＝目的地に設定

■ 操作
  ↑ / ↓        アクセル / ブレーキ
  ← / →        車線変更（一般道ではハンドル）
  Q / E・1～9   次の分岐で進む道路を選ぶ（選ばなければ直進）
  T            分岐おまかせ ON/OFF
  P            近くの名所へ寄り道してスタンプをもらう
  Enter        寄り道から高速道路に戻る
  B            スタンプ帳
  M            日本地図（右クリックでナビ設定）
  C            視点切り替え
  F            給油（都市に停車中）
  Space        早送り
  N（2回）     タイトルに戻る
  V            乗り物切替（スポーツカー → 戦車 → 水陸両用輸送車 → 馬 → 飛脚）

■ ヘリコプター・飛行機（フリーモードのみ）
  V で乗り換え。Space で上昇、Shift で下降、←→ で旋回、↑↓ で速度。
  ヘリコプター：その場で真上に上昇でき、空中で止まれます。
  飛行機：↑で加速し、140km/h 以上で Space を押すと離陸。遅すぎると失速して落ちます。
  高く飛ぶほど遠くまで見渡せます（最高 高度3万m）。空からでも名所の近くを通ればスタンプがもらえます。

■ 馬・飛脚
  馬は旗指物を背負った侍が乗り、飛脚は状箱を担いで走ります。どちらも燃料いらず。
  日本一周モードでは馬は最高70km/h、飛脚は35km/h。フリーモードでは制限なし。

■ 戦車
  マウス・Z/X        砲塔を回す
  左クリック・Ctrl   発射（撃たれた車はくるくる飛んでいきます）
  C                  砲手視点

■ 水陸両用輸送車
  フェリー航路を自力で航行できます（料金なし・最高45km/h）。
  橋の上で ← を押し続けると左端から海へダイブ！ 陸に着くと自動で上陸します。

■ 沖縄海上大橋
  鹿児島 → 奄美 → 那覇 を結ぶ全長680kmの超巨大橋です。

■ サウンド
  F2 で BGM、F3 で効果音（エンジン音など）を ON/OFF できます。設定は保存されます。

■ セーブ
  名所スタンプ・撃破数・乗り物・日本一周の記録（クリア回数・最速タイム）・
  フリーモードで最後にいた場所は自動で保存されます（30秒ごと・スタンプ獲得時・終了時）。
  保存先：%LOCALAPPDATA%\JapanDrive3D\save.json（消すと最初からになります）
  ※ 日本一周モードの途中経過は保存されません。

■ 自動更新
  起動すると GitHub に新しいバージョンがないか確認します（ネットにつながっていなければ確認しません）。
  新しいバージョンがあるとタイトル画面に表示されるので、U キーで更新、R キーで再起動します。
  O キーでダウンロードページを開くこともできます。セーブデータは更新しても残ります。
  ※ Program Files など書き込めない場所に置いた場合は、自動更新できないので手動で更新してください。
  今のバージョンはタイトル画面の右下に出ています。

■ アンインストール
  このフォルダを削除するだけです。
  フォント用の一時ファイルが %LOCALAPPDATA%\JapanDrive3D にあるので、気になる場合はそちらも削除してください。
